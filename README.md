# Dra. Virgínia Aragão

Landing page da [Dra. Virgínia Aragão](https://www.instagram.com/dra.virginiaaragao/), implantodontista em Fortaleza — implantes, ortodontia, alinhadores e odontologia estética.

Estrutura inspirada na [Clínica Lousada](https://clinicalousada.com.br/): hero com chamada para agendar, carrossel de tratamentos, apresentação da doutora, atendimento personalizado, dica clínica e endereço.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```
